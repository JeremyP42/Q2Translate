`2 / 4 / 6 / 8 / 12 / 16 / 24 px`

Микро-шкала (вертикальный ритм списков): **2 px**

## Высоты

- Контрол (кнопка / поле / комбобокс / чекбокс / спинбокс): **30 px**
- Панель окна (TitleBar / HistoryBar / ServicesRow / LanguageBar): **40 px**
- Строка таблицы (по умолчанию): **30 px**
- Строка таблицы с `QKeySequenceEdit`: **32 px** — редактор 30 px прижат к верху, 2 px остаются разделителем. Раньше строка считалась 42 px при фактических 36: поля съезжали вниз и наезжали на следующую строку, а под таблицей оставался пустой блок.
- Таблица горячих клавиш переопределяет вертикальный padding ячеек: `QTableWidget::item { padding: 1px 6px 0px 6px; }` (локально для `m_hotkeyTable`). Глобальный `QTableWidget::item { padding: 4px 6px; }` сдвигал вставленные редакторы на 4 px вниз — QTableView позиционирует cell widget по текстовому прямоугольнику. Итог: 1 px сверху, редактор 30 px заканчивается на границе строки, горизонтальный padding 6 px сохранён.

## Сознательные исключения

- `#ServiceDropdown padding-right: 30` — резерв под стрелку-индикатор.
- `QComboBox padding-right: 26` — тот же резерв под стрелку (меняется только вертикаль и левый отступ).
- `QSlider::handle margin: -5px 0` — компенсация размеров бегунка.
- `QComboBox QAbstractItemView::item min-height: 24` — в шкале.
- `QScrollBar::handle min-height: 28` — служебный элемент.
- `screen_capture_window.cpp:147` — формула ширины комбо OCR, намеренно (+30 %).
- `QToolButton minimumWidth(58)` (`options_dialog.cpp:2307`) — семантика не ясна, не трогать до уточнения.
- `m_serviceDropdown->setMinimumWidth(220)` (`main_window.cpp:649`) — дропдаун сервиса в главном окне, не настройки.
- `setMinimumHeight(22)` у строк языковой панели (`main_window.cpp:469/485/502/527`) — нижняя граница ниже фактической высоты из QSS, на вид не влияет.
- `setFixedWidth`/`setMinimumWidth` 90 / 110 / 120 / 142 / 210 / 230 / 250 / 320 — точечные размеры конкретных контролов (спинбоксы, кнопки, дерево, редактор), не «одинаковые по смыслу».
- `QWidget#StatusBar bottom-radius: 9px` — вложенный радиус: `WindowFrame 10px − 1px border`. Не унифицировать с общей шкалой радиусов. При изменении `WindowFrame` пересчитывать по формуле `outer − 1`.
- `QToolTip padding: 2px 6px` — Qt добавляет собственные поля вокруг текста подсказки, поэтому визуальный отступ больше номинала. Цвета берутся из темы (`tooltipBg = surfaceAlt`, `tooltipText = text`), поэтому подсказка совпадает с меню и панелями светлых и тёмных тем.
- Нижняя скруглённая кромка: `WindowBody` прозрачный, а последняя видимая полоса (`ServicesRow` / `HistoryBar` / `StatusBar`) получает свойство `bottomRow="true"` и радиусы `9px` (10 − 1 border). Дочерние виджеты не обрезаются по радиусу родителя, поэтому иначе они закрашивают нижние углы окна квадратом.
- Подсказки сервисов — собственный `ServiceTooltip` (QLabel-панель рисуется вручную, `Qt::NoDropShadowWindowHint`), потому что нативное тень QToolTip прямоугольная и даёт второй острый угол за скруглением.

## Техдолг

- `IconFactory::icon(..., size)` — третий аргумент местами 14 / 15 / 18 при `setIconSize(16)` (13 мест). Пиксмап масштабируется на 1–2 px, визуально приемлемо. При следующей ревизии иконок — поднять третий аргумент до 16 везде. **Кода сейчас не менять.**
