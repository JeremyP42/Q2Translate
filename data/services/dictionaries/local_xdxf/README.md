# Local XDXF dictionaries

This connector does not include dictionary files. Download XDXF dictionaries
separately, for example from:

- <http://www.dicto.org.ru/xdxf.html>
- <https://github.com/orgs/xdxf/repositories>

Put each dictionary in its own subfolder inside the connector folder, or
select any folder with the **Папка словаря** setting. The connector scans the
selected folder recursively for `*.xdxf` files.

XDXF dictionaries are separate data works. Their licenses vary; many are
distributed under the GNU GPL. Check the license of every dictionary before
redistributing it or including it in a package.
